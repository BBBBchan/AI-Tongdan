# 切片风格与证据边界

本模块保留独立切片工具在2026年10月20日至21日整理的公开投稿观察。参考对象是[恨也迷人](https://space.bilibili.com/13490123)、[XING10086](https://space.bilibili.com/274089)、[TDD-珈蓝梦](https://space.bilibili.com/5109111)和[七海Nana7mi单推人](https://space.bilibili.com/896830)。观察包括投稿元数据、封面和部分视频抽帧，不等于完整观看所有视频，也不是随机抽样的效果评测。

用于模型提示的短标题示例及对应公开视频链接保存在 `clipper/reference_titles.json`。仓库不分发参考视频、封面截图或完整抓取档案。

## 如何转化成切片规则

- **标题具体。** 使用当前片段里的原话、误会、动作或结果，让一句有趣的话本身成立；避免统一写成“主播吐槽某事，弹幕笑疯”。标题以 `【主播短称】` 标识人物；示例中的人名、数字和关系不能直接移植。
- **选段完整。** 生活故事、观点、游戏事件、联动和表演都可以成为看点，不强制套用“发言—弹幕—回应”。常规目标约2–5分钟，完整的话题可以更长；自动投稿至少60秒，不填充无关素材凑时长。
- **简介和标签有依据。** 简介说明当前片段并保留主播与直播来源。标签依据真实人物、内容和分区选择，不把参考账号的全部标签机械复制到每条稿件。
- **画面有重点。** 封面使用当前切片的实际画面，粗体短文案分层；避免左下角易遮挡区域。横屏保留直播全景，成片输出1080P，字幕经完整音频复听后烧录。
- **弹幕强调适量。** 默认不放大。确有必要时，必须在原视频帧中找到真实文字、位置和时间，再做短暂、轻量的原位放大；无法可靠定位就省略，不按接口收到弹幕的时刻提前显示。

例如，[生活经历](https://www.bilibili.com/video/BV1CuJq68EWU/)说明非互动内容也可以有独立看点；[观点原话](https://www.bilibili.com/video/BV1Erng6mEEb/)可直接构成标题。示例用于解释写法，不证明本系统自动生成的候选必然有趣。

## 质量判断

模型分数只是选段信号。导出和投稿仍需检查语境、真实事件ID、连续字幕引用、时间范围、来源重叠、整段复听及独立内容审稿。旧校验误拦可以有界重审，不能因为改了标题就跳过检查。模型不可用时只保留明确标记的候选，不把规则筛选当作完成的语义分析。

当前实现导出连续片段，没有宣称支持自动多段跳剪或无台词的纯视觉高光。抽帧观察也不能证明参考视频的完整音效、转场和叙事节奏。
