# 首页 GIF 演示说明

这三段 GIF 使用 AI同担的真实网页组件，配合**隔离的示例数据**录制。每段顶部均标注“交互示意 · 示例数据”。它们用于说明界面和操作方式，不是实时直播实录，也不代表模型的识别准确率、回答速度或端到端延迟。

## 内容来源

- 页面直接使用仓库中的 `static/index.html`、`static/app.css` 和 `static/app.js`。
- “同担电台”画面由浏览器 Canvas 绘制；歌名、字幕、观众昵称、弹幕、观察记录和回答均为虚构示例。没有使用真实主播的直播画面或语音。
- 模拟事件按既定顺序回放，问答显示进度经过安排；实际体验取决于模型、硬件、网络与直播内容。
- 弹幕演示仅选取候选内容和复制文本；没有登录 Bilibili，也没有向直播间发送弹幕。GIF 不含声音。

## 录制方法

使用 Playwright 打开现有网页，在独立浏览器上下文中拦截全部 `/api/` 请求，并以本地示例对象替换状态和事件流。只有页面和静态资源请求会到达应用服务；演示中的提问也由隔离层接收，不会改变正在运行的直播会话。

操作由网页已有按钮和输入框完成；录制额外添加了顶部说明条与光标提示，并裁取对应功能区域。浏览器逐帧截图后，以 FFmpeg 转换为每秒 8 帧、循环播放的 GIF。图标原图未作修改。

录制后逐段检查关键帧、候选弹幕填入结果、复制反馈、连续问答与同期观察，确认未出现浏览器错误，也没有展示凭据、模型接口地址或私人会话内容。
